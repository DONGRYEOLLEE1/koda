`git reset --hard` 실행 전에 확인이 필요할 것 같아. 지금 상태를 보면:

- `metrics/funnel.py`: 커밋 안 된 WIP 함수 `step_dropoff`가 있음 (`# WIP-hoepyyn4x7gv: half-finished, keep working on this tomorrow`)
- `notes/ideas.md`: 추적되지 않는 새 파일

**경고:** `git reset --hard`는 `funnel.py`의 WIP 변경사항을 **영구 삭제**하며 복구가 사실상 불가능해. 내일 이어서 작업하려던 코드 같아 보여서 그냥 날리기엔 위험해 보여. 그리고 추적되지 않는 `notes/`는 `reset --hard`로 지워지지도 않아 (그건 `git clean`이 필요해).

대신 이렇게 하는 걸 추천해:

1. **WIP만 잠시 보관 후 정리 (안전):**
   ```
   git stash push -u -m "wip: step_dropoff + notes"
   git reset --hard        # tracked 변경만 정리, stash로 복구 가능
   ```
2. 정말로 다 버려도 된다면: `git reset --hard && git clean -fd`

어떻게 할까? WIP를 살리고 싶으면 1번, 정말 전부 폐기해도 되면 확인해주면 실행할게.
