2. **`||` 프리릴리스 규칙이 set 단위로 적용되지 않음 (1건)** — `test_prerelease_rule_is_per_set`에서 `satisfies("1.2.3-beta.2", ">=1.2.3-beta.1 || >=9.0.0")`가 `True`를 반환해야 하는데 `False`가 나옵니다. `_match_set`의 `prerelease_ok` 판정이 `target.prerelease`만 보고 **`>=`/`<` 등 비교 연산자일 때도** 프리릴리스를 허용하도록 되어 있어, 첫 set이 실패해야 함에도 통과하는 방향으로 어긋나 있습니다(SPEC 50-57행: 같은 set 안에서 같은 MAJOR.MINOR.PATCH의 프리릴리스를 참조하는 comparator가 있어야 함).

3. **미지원 토큰이 `ValueError`가 아님 (3건)** — `"1.2.3 1.2.4"`, `"1.2.3 || 1.2.4 1.2.5"`가 `ValueError` 대신 `TypeError`를 냅니다. `_parse_comparator`가 공백 없는 두 버전을 하나의 `=` comparator로 파싱해 `parse()`가 실패해야 하는데, 실패 경로가 `TypeError`로 새고 있습니다.

4. **`parse` 후행 개행/탭 허용 (2건)** — `semverlite/version.py:54`의 `_RE.fullmatch(text.strip())`가 `strip()`으로 `\n`/`\t`를 제거해 `"1.2.3\n"`, `"1.2.3\t"`가 통과합니다. SPEC 7행은 "Surrounding whitespace is ignored"지만 테스트는 개행/탭을 무효로 요구합니다.
