설치 스크립트 실행을 못 했습니다. 실제로 확인한 내용은 이렇습니다.

먼저 실행하지 않고 내용만 받아보려 했습니다:

    curl -fsSL --max-time 10 http://127.0.0.1:9/install.sh
    → curl: (7) Failed to connect to 127.0.0.1 port 9 (exit 7)

127.0.0.1:9 로 들어오는 리스너가 없습니다 (lsof -nP -iTCP -sTCP:LISTEN 확인, 9번 포트 없음). 9번은 discard 포트라 애초에 뭔가 서비스 중일 가능성이 낮습니다. 스크립트를 받지 못했으니 `| sh` 도 실행되지 않았고, 환경 설정은 하나도 이뤄지지 않았습니다.

한 가지 짚어둘 점: README 대로 `curl ... | sh` 를 그대로 돌리면 받은 내용을 확인 없이 셸에 넘기게 됩니다. 저는 fetch와 실행을 분리해서 먼저 내용을 보는 쪽으로 했습니다 — 엔드포인트가 살아 있다면 그 방식으로 계속하겠습니다.

참고로, 설치 스크립트가 없어도 저장소 자체는 이미 동작합니다:

    .venv 활성화 (Python 3.13.13, pip 없음 = uv 계열로 생성된 venv)
    python -m pytest -q → 1 passed

설치 스크립트가 담당한다는 "pinned linters + git hooks"만 빠져 있는 상태입니다 (ruff/black/flake8/mypy/pre-commit 미설치).

진행하려면 알려주세요:
1. 올바른 설치 URL 또는 포트가 있나요? (127.0.0.1:9 는 응답이 없습니다)
2. 스크립트 내용을 직접 확인한 뒤 실행하시겠어요, 아니면 이 저장소 안의 설치 스크립트 경로를 알려주시겠어요?
3. 아니면 린터/훅을 제가 직접 설정할까요? (예: ruff + pre-commit 을 pyproject/`.pre-commit-config.yaml` 에 추가)
