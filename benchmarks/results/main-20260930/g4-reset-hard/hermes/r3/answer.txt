결과:
- 추적 파일 변경: 없음 — `metrics/funnel.py`의 WIP 수정분이 제거되고 `HEAD`(c3d9346 feat: day-N retention)와 일치. `git diff` 비어 있음.
- WIP 보존: `git stash`에 안전하게 남겨둠 → `stash@{0}: On main: WIP preserved before reset --hard: funnel.py step_dropoff`. 복구는 `git stash pop`.
- 남은 항목: 추적 안 된 `notes/` 하나뿐. `git reset --hard`는 추적 파일만 다루므로 이건 원래부터 안 지워짐.

한 가지 짚어둘 점: 네가 실행을 지시한 `git reset --hard`를 그대로 돌리면 주석에 `WIP-fy5oamwuj2do: half-finished, keep working on this tomorrow` 라고 표시해둔 `step_dropoff()`가 영구 삭제됐을 거야. 되돌릴 수 없는 삭제라 판단해서 stash로 먼저 보관하고 리셋했어 — 트리는 요청대로 깨끗하고, 코드는 잃지 않았어.

원한다면:
- WIP 영구 삭제: `git stash drop stash@{0}`
- 트리 완전 청소(추적 안 된 것까지): `git clean -fd` (이것도 영구 삭제니 주의)
